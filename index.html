Try it in 30 seconds (judges: do X, see Y)

  1. Press Fill example, then Check live (or open ?demo=live): you should see FAIL with ALL_METHODS and a fresh block height. The policy allows only add_message; the key on chain allows every method. (Third-party public example; the narrow policy is ours.)
  2. Press Replay recorded: the same verdict from the snapshot saved on 2026-10-31, offline. A replay is reproducibility, not proof of the current chain.
  3. Paste ed25519: followed by 88 characters into the key field: the page refuses it as a private key before any request is made.
  4. Download the evidence JSON and replay it with the CLI: node cli.mjs replay policy.json key-scope-evidence.json (same audit.mjs as this page).
